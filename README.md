Captures live network packets and displays source IP, destination IP, protocol (TCP/UDP), ports, and packet size.

## Requirements
- Python 3
- Npcap (Windows) - https://npcap.com
- Scapy library

## Installation
pip install scapy

## How to run
Run terminal as Administrator, then:
python sniffer.py

## Example output
Source IP: 192.168.1.5
Destination IP: 142.250.74.46
Protocol: TCP
